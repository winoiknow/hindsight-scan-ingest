*Create a python application to ingest documents in a certain folder or multiple folders into Vectorize Hindsight. Hindsight is running locally in docker, not in the cloud.

Requirements:

- Must be able to scan and ingest any document type, i.e., txt, md, docx, pdf, etc..
- Must be able to use Tesseract as an OCR to scan images for data to upload.
- Must have knob to adjust how frequently it scans the document. ie, 5min, 15min, 60min.
- Must have knob to adjust the server URL. default should be http://localhost:8888
- Must have knob to add path to folder to watch and the ability to add multiple folders.
- knob to set the correct memory bank, source and/or session of the data so that it can match whichever agent hindsight will connect to.
- plan for testing validity and function of app.
- create a README.md and push to new repo on GitHub.
